# Treact Landing Page

A responsive recreation of a modern template marketplace landing page, built as a course final project.

## Features

- Responsive navigation
- Feature and pricing sections
- Testimonials and FAQ content
- Mobile menu
- Reusable layout patterns

## Built With

- HTML
- CSS
- JavaScript

## Requirements

No Node.js installation is required.

## Run Locally

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/Miingo954/final-project.git
cd final-project
open index.html
```
